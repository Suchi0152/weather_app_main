# Weather App


## Project Overview


The Weather App is a Flutter mobile application that allows users to search for a city and view its current weather information.


## Project Purpose


The purpose of this application is to provide users with a simple and convenient way to check weather conditions for different cities.


## Objectives


- Create a functional weather application using Flutter.
- Allow users to search for different cities.
- Display weather information clearly.
- Practice Flutter and Dart programming.
- Learn how to connect an application to a weather API.
- Use Git and GitHub for version control.


## Target Users


The application is designed for:


- Students
- Travellers
- Workers
- General users who want to check the weather


## Core Features


- City search
- Weather information display
- Temperature display
- Weather condition display
- Simple and user-friendly interface
- Weather API integration


## User Journey


1. The user opens the Weather App.
2. The app displays the weather screen.
3. The user enters the name of a city.
4. The user searches for the city.
5. The application requests the weather information.
6. The weather information is displayed on the screen.
